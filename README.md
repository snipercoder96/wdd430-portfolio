# WDD430 Portfolio Project

This repository contains my portfolio project for WDD430 - Full-Stack Web Development.

## Deployment
The project is deployed on Vercel.  
You can access the live site here:  
👉 https://wdd430-portfolio.vercel.app

## Purpose
- Showcase assignments and projects completed in WDD430.
- Demonstrate Next.js application setup and deployment workflow.
- Provide a central place for teammates and instructors to review code and functionality.

## How to Run Locally
1. Clone the repository:
   git clone https://github.com/snipercoder96/wdd430-portfolio.git
2. Navigate into the project folder:
   cd wdd430-portfolio
3. Install dependencies:
   npm install
4. Start the development server:
   npm run dev
5. Open http://localhost:3000 in your browser.
